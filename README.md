# 混合逆变器运行模式介绍 · 能量拓扑可视化演示

**展厅大屏 / 客户演示 / 产品介绍**专用的能量拓扑可视化展示脚本。

## 这是什么

一个开箱即用的**交互式演示页面**：展示混合逆变器在并网 / 离网 / 柴发 / SMARTLOAD 等运行模式下的能量流向拓扑图，支持切换模式与附加条件，实时观看能量流动效果。

## 如何使用

1. 下载本仓库中的 `拓扑编辑器_演示版_V6_28.html`
2. 用浏览器（推荐 Chrome / Edge）直接双击打开
3. 右侧面板点击不同模式（并网模式 / 离网模式 / 柴发模式 / SMARTLOAD 模式）及附加条件，查看能量流向实时变化
4. 点击 **AUTO** 按钮可自动循环演示各种模式与条件组合

## 演示特点

- 多种粒子流动效果（光点 / 箭头 / 心电图 / 闪电 / 星芒等 10+ 种）
- 每个模式独立的条件组配置，实时联动设备高亮、隐藏、连线流向
- 全屏可缩放拖动画布，适合展厅大屏投放
- 单文件自包含，无需安装任何软件
